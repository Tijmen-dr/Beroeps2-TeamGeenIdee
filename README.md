Om deze pagina te laten werken heb je allen files nodig uit de CSS HTML JAVASCRIPT images include en views folder nodig. (databases folder is optioneel).
Wij raden je aan om het zelfde connectie script te gebruiken die in include/config.php staat.
Deze file roept ons database aan op onze remote server.
Het is ook mogelijk om de geëxporteerd database files te gebruiken, alleen is de pagina geoptimalizeerd voor de remote database.
Je zal dan zelf het config.php bestand moeten herschrijven zodat het werkt met de databases in de folder.
Verder ben je vrij om de code over te nemen, aan te passen, of je eigen twist eraan te geven.
Zolang de footer onderaan elke pagina blijft staan, dan vinden wij het geen probleem dat de code gebruikt wordt.
